# 《每阶段过关标准》

> 适用对象:英语单词学习应用所有用户。
> 文档定位:本文档定义四个学习阶段(初中 / 高中 / 大学 / 雅思)的**通关标准**,把"会背单词"量化为可测量的硬指标。所有用户在每季度大循环结束时,需对照本表做一次"过段考核",达标后才能升入下一阶段。

---

## 0. 总览:六大考核维度

每个阶段的"过关"都基于以下六维指标,任意一项未达标即视为本阶段未通过,需在下一季度补足后再考核。

| 维度 | 衡量内容 |
| --- | --- |
| **A. 词汇量目标** | 已掌握词数 + SRS 间隔 ≥ 35 天的词数 |
| **B. 总正确率** | 应用内全模式累计正确率 |
| **C. i+1 短文阅读** | 阅读完成篇数(每篇 ≥ 250 词) |
| **D. Feynman 复述挑战** | 完成次数(每次至少复述 5 个新词) |
| **E. 错题本清空率** | 累计错题被清空的比例 |
| **F. 发音测评平均分** | 应用内置 T9 发音测评得分(百分制) |

> 所有指标均在"应用仪表盘"中自动统计,无需手填。

## 5. 跨阶段软性建议(非硬性指标)

- **学习习惯粘性**:连续 90 天打开应用率达 90% 以上,可获得"全勤毕业生"称号。
- **方法迁移能力**:能否在某阶段证明"用了至少 6 种方法"?(在仪表盘的"方法档案"中可见)
- **错题复盘质量**:错题本中的每一条错题,是否都附有"为什么错 + 如何改进"?

## 如何最大化利用本指南

1. **把它当作"游戏关卡"**:每达一维解锁一格进度条,六维全亮 = 通关。
2. **数字化阅读这些数字**:不要"凭感觉"判定毕业,所有指标从仪表盘读。
3. **失败不是问题**:任何一维未达标,先延长一季度再做;不要"硬跳段"。
4. **维度之间的矛盾**:若 A 达标但 B 仅 75%,优先补 B;因为 B 是"运用能力",B 不到位说明有学但没用。
5. **坚持比完美更重要**:即使你没有全部达标,坚持 4 个季度也远胜于 1 个季度"硬冲"。
6. **结业徽章只是里程碑**:不是终点;每段结束后再主动学 1 个月,稳固新阶段的基础。

> 词汇学习是"看得见的进步 + 看不见的坚持"。指标是给你看的,坚持是你要给时间的。让每一个硬指标都成为你学习的方向标。

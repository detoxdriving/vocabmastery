# 英语单词科学记忆规划 Spec(v2 · 增强版)

## Why
用户希望以世界最先进的英语学习法与记忆力训练法为理论根基,系统性攻克 **初中 → 高中 → 大学 → 雅思** 四阶段词汇,达成长期记忆(LTS),而非"背了就忘"。同时用户要求:
1. **参考国内外主流背单词软件的优劣势**,取长补短,做出超越市面上产品体验的工具;
2. **多维度统计**(背对率、理解率、发音正确率等),让进步可视;
3. **背诵模式 + 检验模式独立**,遵循"输入 → 巩固 → 测评"的科学闭环。

## What Changes
- 整合科学记忆体系:艾宾浩斯 + SM-2 SRS + 主动回忆 + 精细化编码 + 双重编码 + 记忆宫殿 + 关键词法 + 交错练习 + 生成效应 + 组块 + i+1 语境 + Feynman。
- 建立四阶段词库(初中 1600 / 高中 3500 / 大学 6000–8000 / 雅思 4000+)分层结构。
- 设计 **背诵模式** 与 **检验模式** 两大独立训练通道。
- 提供 8 项统计维度 + 17 项细分指标 的可视化仪表盘。
- 实现纯前端离线 Web 学习应用(HTML + JS + localStorage)。

## 📊 国内外主流背单词软件竞品分析

### 国际阵营

| # | 软件 | 算法 | 优点 | 缺点 |
|---|------|------|------|------|
| 1 | **Anki**(开源) | FSRS / SM-2 | 算法最强大、完全可定制、跨平台、卡片支持音视频图片、社区资源海量化 | UI 丑、初始设置复杂、无内置词库、自制卡耗时 |
| 2 | **SuperMemo**(原算法发明者) | SM-2 至 SM-18 | 算法最严谨(科学研究级)、曲线最准 | 学习曲线极陡、UI 丑、收费 |
| 3 | **Quizlet** | 自研 SRS | UI 友好、模式多(闪卡/学习/匹配/重力/测试)、社区卡组丰富 | SRS 较弱、免费版广告、深层记忆功能弱 |
| 4 | **Memrise** | 自研 SRS + 间隔 | 真人视频例句、科学间隔、游戏化、内置课程 | 高级内容付费、社交化过强 |
| 5 | **Brainscape** | 自研 CS 算法(置信度评级) | 主动回忆强度高(0–5 评分) | 词库偏专业、UI 一般 |
| 6 | **Duolingo** | 自研 | 游戏化最强、免费、初学者友好 | 翻译式学习、词汇深度不足、不适合应试 |
| 7 | **Clozemaster** | 填空驱动 | 大量真实语境填空、TTS 朗读 | SRS 弱、UI 一般 |
| 8 | **LingQ** | 阅读驱动 | 阅读量极大、导入便捷、生词高亮 | SRS 弱、付费门槛高 |
| 9 | **WordUp** | 词频排序 | 真正基于 2 亿语料的使用频率 | 内容激进、可能跳过应试高频 |
| 10 | **Busuu** | 课程体系 | 有母语者批改、CEFR 分级完整 | 订阅价格高 |

### 国内阵营

| # | 软件 | 算法 | 优点 | 缺点 |
|---|------|------|------|------|
| 1 | **墨墨背单词** | 经典 SRS | 统计极详细(遗忘曲线/记忆持久度)、助记丰富(谐音/词根/象形)、签到打卡 | 单词上限(超量付费)、新词少 |

| 8 | **可可英语** | 综合 | 资源丰富 | 功能分散、背词非核心 |
| 9 | **Anki中国**(汉化版) | FSRS | 算法强、中文社区资源多 | UI 仍丑、上手门槛高 |
| 10 | **Quizlet 中文版** | 同国际 | 资源本地化 | 算法同 Quizlet |

### 综合结论:本工具的差异化定位

> **取长补短策略**:
> 1. ✅ **采用**:墨墨的**详细统计** + Anki/SuperMemo 的**算法** + 扇贝的**多模式** + Memrise 的**真实语境** + 不背单词的**影视例句** + 拓词的**拼写训练**。
> 2. ❌ **规避**:Anki 的丑 UI、墨墨的单词上限、Quizlet 的弱 SRS、百词斩的过度图片化、Duolingo 的翻译式。
> 3. 🆕 **创新**:**背诵模式 + 检验模式独立**(市面上几乎无产品分离这两者),**发音正确率统计**(基于 Web Speech API 评分),**易混淆词自动识别**,**反应时间记录**,**学习热力图**。

## ADDED Requirements

### R1: 四阶段词库分层与词表导入
系统 SHALL 提供四大词库(初中 / 高中 / 大学 / 雅思),每阶段词表使用**词频优先**排序;按词族(Word Family)与主题场景分组。

#### Scenario: 用户选择词库
- **WHEN** 用户点击"选择词库 → 初中 / 高中 / 大学 / 雅思"
- **THEN** 系统展示该词库总词数、预估学习天数、当前已学/未学/已掌握数量,并允许按词族、主题或字母筛选。

#### Scenario: 词表数据持久化
- **WHEN** 用户首次使用或切换词库
- **THEN** 词表 JSON 自动写入 `localStorage`,后续访问无需重新加载网络。

---

### R2: 基于 SM-2 算法的间隔重复复习(SRS)
系统 SHALL 使用 SuperMemo SM-2 间隔重复算法,为每张词卡计算下一次复习时间(1d → 3d → 7d → 16d → 35d),根据用户反馈质量因子 q(0–5)动态调整 EF 系数。

#### Scenario: 用户评分单词
- **WHEN** 用户在复习界面点选 Again / Hard / Good / Easy
- **THEN** 系统按 SM-2 公式更新 EF、下次间隔、下次复习日期。

---

### R3: 多模态记忆法
每个单词 SHALL 同时提供:拼写、发音、英文释义、中文释义、英文例句、词根词缀、词族、同义/反义、搭配、联想图像 共 10 个记忆锚点。

#### Scenario: 查看单词详情
- **WHEN** 用户点击单词卡片
- **THEN** 卡片翻转展示音标/词根/释义/3 例句/词族/搭配,并提供"听音"按钮触发 Web Speech API 朗读。

---

### R4: 关键词法与记忆宫殿
- **关键词法 (Keyword Method)**:为抽象词提供发音相似的中文锚词 + 荒诞短句。
- **记忆宫殿 (Method of Loci)**:用户为一批关联词创建"宫殿场景",按空间顺序为每词生成视觉锚点。

#### Scenario: 创建记忆宫殿
- **WHEN** 用户进入"记忆宫殿"模块,选择主题(如"厨房")并添加 5–20 个单词
- **THEN** 系统按顺序为每词生成场景画面描述,允许编辑保存。

---

### R5: 语境阅读(i+1)
系统 SHALL 内置短文阅读模块:每 50 个目标词匹配一篇 200–300 词短文,生词率 5–10%(Krashen i+1),阅读中可点词查义并加入复习队列。

---

### R6: 主动回忆与生成式输出
- 单词先隐藏中英文,要求用户在心里/纸面写出或造句,然后再揭示。
- 每周提供 Feynman 复述挑战:随机抽取 20 词写 100 词小短文或口头讲解。

---

### R7: 📚 背诵模式(独立通道)
系统 SHALL 提供 **独立于 SRS 复习的"背诵模式"**,允许用户专门进行"新词初学 / 巩固训练",不走 SRS 队列,以**主动回忆**为核心,允许多种变体:

| 模式 ID | 模式名 | 操作 | 适用场景 |
|---------|--------|------|----------|
| L1 | **看英回忆** | 看到英文,回忆中文释义、词性、用法 | 初次接触、被动再认 |
| L2 | **看义回忆** | 看到中文,回忆英文拼写 | 强化产出能力 |
| L3 | **听音辨义** | 听到发音,选择正确词义 | 强化听力 + 音义联结 |
| L4 | **听音写词** | 听到发音,输入英文拼写 | 强化拼写 + 听力 |
| L5 | **拼写强化** | 看释义,逐字母拼写单词 | 拓词式拼写训练 |
| L6 | **例句填空** | 在例句空格中填入正确单词 | 语境掌握 |
| L7 | **词族派生** | 给出一词,联想其派生词 | 举一反三 |
| L8 | **配图记忆** | 看图像选词 / 看词选图 | 双重编码(百词斩式) |
| L9 | **关键词 + 联想图** | 关键词法故事 + 视觉符号 | 抽象词记忆 |
| L10 | **跟读训练** | TTS 朗读 → 用户跟读 → 录音对比 | 发音矫正 |

#### Scenario: 选择背诵模式
- **WHEN** 用户进入"背诵模式"模块
- **THEN** 系统展示 10 种模式卡片,可单选/多选混合;选定后从"未掌握词"队列抽取词卡。

#### Scenario: 背诵模式进度独立
- **WHEN** 用户在 L1–L10 中任意模式完成一轮
- **THEN** 该轮的"答题记录 / 正确率 / 反应时间"独立存储,不污染 SRS 主队列,但允许用户主动"标记掌握"将其移入 SRS 复习队列。

### R8: ✅ 检验模式(独立通道)
系统 SHALL 提供 **独立于日常训练的"检验模式"**,模拟考试场景,专门用于**测评掌握度**,覆盖以下题型:

| 模式 ID | 模式名 | 题型 | 适用阶段 |
|---------|--------|------|----------|
| T1 | **单元测验** | 随机 N 词,混合选择题 + 填空题 + 拼写题 | 每学完 50 词 |
| T2 | **看英选义** | 4 选 1(英文 → 中文) | 初中 / 高中 |
| T3 | **看义选英** | 4 选 1(中文 → 英文) | 高中 / 大学 |
| T4 | **听音辨义** | 4 选 1(音频 → 中文) | 全阶段 |
| T5 | **听写测试** | 听音频后逐字输入 | 高中以上 |
| T6 | **释义连线** | 8–10 词与 8–10 释义匹配 | 强化形义对应 |
| T7 | **完形填空** | 一段短文挖空 5–10 词 | 雅思 / 大学 |
| T8 | **词族测试** | 给出一词,选其正确派生 | 大学 / 雅思 |
| T9 | **发音测评** | 跟读单词 → 评分(基于 Web Speech API + 语音相似度) | 全阶段 |
| T10 | **综合模拟考** | 雅思 5–7 词块混合题(70 题/45 分钟) | 雅思 |

#### Scenario: 启动检验模式
- **WHEN** 用户进入"检验模式"模块,选择词库范围(如"初中 / 第 1–50 词")与题型
- **THEN** 系统生成试卷并启动倒计时,完成后给出**逐题解析 + 错题本 + 成绩报告**。

#### Scenario: 检验结果入错题本
- **WHEN** 用户在 T1–T10 中答错
- **THEN** 错词自动加入"错题本",并入 SRS 复习队列的高优先级位置(下次复习间隔缩短)。

### R9: 📈 多维统计与可视化(8 大维度 / 17 项指标)
系统 SHALL 提供 **远超墨墨/百词斩/扇贝的详细统计仪表盘**,覆盖以下维度:

#### 维度 1:词汇量统计
| 指标 | 定义 |
|------|------|
| 1.1 总词数 | 当前词库总词量 |
| 1.2 累计已学 | 至少 1 次接触的词数 |
| 1.3 已掌握 | SRS 间隔 ≥ 35 天的词数 |
| 1.4 待复习 | 今日到期复习词数 |
| 1.5 未学习 | 尚未接触的词数 |
| 1.6 各阶段进度 | 初中/高中/大学/雅思各自的(已学/总词数)百分比 |

#### 维度 2:正确率细分(必含!)
| 指标 | 定义 |
|------|------|
| 2.1 整体正确率 | 所有题型总答题正确率 |
| 2.2 初中正确率 | 初中阶段分项正确率(整体 / 各题型 / 各词族) |
| 2.3 初一正确率 | **细到初一年级**(可在设置中定义分组,默认按学期) |
| 2.4 高中/大学/雅思正确率 | 同上 |
| 2.5 题型正确率分布 | L1–L10 + T1–T10 各题型正确率雷达图 |
| 2.6 主题正确率 | 按主题(食物/交通/科技/...)正确率 |

#### 维度 3:理解率(语义层面)
| 指标 | 定义 |
|------|------|
| 3.1 释义准确率 | 看义选英、看英选义题型正确率 |
| 3.2 语境理解率 | 例句填空、完形填空正确率 |
| 3.3 词族理解率 | 词族派生题型正确率 |
| 3.4 搭配掌握率 | 词块搭配题正确率 |

#### 维度 4:发音正确率(创新指标)
| 指标 | 定义 |
|------|------|
| 4.1 发音评分 | 跟读训练(T9)由 Web Speech API 评分 0–100 |
| 4.2 音节切分正确率 | 用户对单词音节的拆分准确度 |
| 4.3 重音位置正确率 | 多音节词重音标注准确度 |
| 4.4 易错发音 Top 10 | 评分最低的 10 个词,供重点突破 |

#### 维度 5:记忆持久度
| 指标 | 定义 |
|------|------|
| 5.1 记忆持久度 | SM-2 EF 系数均值,反映整体记忆稳固度 |
| 5.2 预测遗忘率 | 基于艾宾浩斯曲线,预测未来 7 天可能遗忘的词数 |
| 5.3 记忆曲线 | 已学词在不同时间点的回忆率曲线(应呈下降后回升) |

#### 维度 6:效率指标
| 指标 | 定义 |
|------|------|
| 6.1 日均学习量 | 近 7 / 30 / 90 天平均每日新词数 |
| 6.2 日均复习量 | 近 7 / 30 / 90 天平均每日复习数 |
| 6.3 反应时间均值 | 单题平均答题耗时(秒) |
| 6.4 学习热力图 | 365 天 × 24 小时 学习强度热力图(GitHub 贡献图风格) |
| 6.5 连续打卡 Streak | 连续学习天数 |
| 6.6 单次会话时长 | 平均学习会话时长(分钟) |

#### 维度 7:错题分析
| 指标 | 定义 |
|------|------|
| 7.1 错题总量 | 累计答错次数 |
| 7.2 易错词 Top 20 | 错误次数最多的词 |
| 7.3 易混淆词对 | 算法自动识别用户经常混淆的两个词(如 affect/effect) |
| 7.4 拼写错误统计 | 用户拼错的字母位置热力图(如 QWERTY 键盘位置) |

#### 维度 8:进度可视化
| 指标 | 定义 |
|------|------|
| 8.1 四阶段进度条 | 初中/高中/大学/雅思 各自的进度条 |
| 8.2 最近 30 天学习曲线 | 柱状图(每日新学 + 复习) |
| 8.3 雷达图 | 题型正确率 / 主题掌握度 |
| 8.4 遗忘曲线模拟 | 图形化展示预测记忆衰减 |

#### Scenario: 查看仪表盘
- **WHEN** 用户进入首页或统计模块
- **THEN** 系统展示上述 8 大维度,采用仪表盘卡片 + 图表(柱状/折线/雷达/热力图)形式呈现,可按词库(初中/高中/大学/雅思)与时间范围(7d/30d/90d/全部)筛选。

#### Scenario: 阶段细分(初一细粒度)
- **WHEN** 用户在统计模块选择"初中 → 初一"
- **THEN** 系统仅展示初一年级词库的上述所有指标,且支持进一步筛选"初一上 / 初一下"。
